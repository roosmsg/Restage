The first release of Restage, a workspace manager for Windows 11.

Restage saves the applications you have open as a workspace: VS Code folders, Obsidian vaults and notes, Firefox and Chrome profiles and web apps, Explorer folders, terminals and any other app, with every window's position, the virtual desktop and its wallpaper. **Start** brings it all back, on each monitor arrangement you have saved a layout for.

## What's in it

- **Workspaces as cards** in a gallery, each with a screenshot. *Update* adds the current monitor arrangement to a workspace.
- **Per item**, in the details pane: include it or not, and *reuse if open* or *always launch*.
- **Per workspace**: a global keyboard shortcut that starts it, or brings its windows to the front when it is already open, and whether its wallpaper is applied.
- **A shortcut to open Restage** from anywhere, which also puts it away again.
- **Connect apps**: other apps on the same PC can start, switch and save workspaces through a small local API: a voice tool such as [Hex](https://anoma.ly/hex) or Handy, a Stream Deck button, a script. Settings › *Connect apps* gives the address and token; they stay the same across restarts. Commands can be spoken in English or Dutch ("open research", "save this as Thesis"). See [docs/API.md](https://github.com/roosmsg/Restage/blob/main/docs/API.md).
- **Tray icon**, in colour or monochrome to match the taskbar, with a loading ring while a workspace starts; it can also be hidden.
- **`restage` command line**: list, inspect, start and save workspaces from a shell.
- Light and dark mode following Windows, in your Windows accent colour.

Everything stays on your PC: no telemetry, no network connections; the local API listens on the loopback address only and needs the token.

## Install

- **`Restage-Setup-v0.1.0.exe`**: per-user installer, no administrator rights. Optionally starts Restage at sign-in and adds `restage` to your PATH.
- **`Restage-v0.1.0-portable-win-x64.zip`**: the app and the command line (`bin\restage.exe`) as self-contained exes; unzip anywhere and run `Restage.exe`.

Windows 11, x64. The files are not code-signed yet, so SmartScreen may warn on first run: choose *More info*, then *Run anyway*. `SHA256SUMS.txt` lists the checksums.

## Known limits

- Explorer tabs come back as separate windows, and browser tabs are each browser's own session restore.
- Only the current virtual desktop's windows are captured.
- Apps running as administrator cannot be read or moved.
